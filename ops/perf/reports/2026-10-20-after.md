## 2. 测量方法与可比性

### 2.1 配对 A/B，而不是拿历史基线直接比
本轮 before/after 都重新测量，且**交替运行**，避免把系统负载漂移当成优化效果：

- 后端：HEAD 源码树（`/tmp/homeos-perf/head-src-clean`）与当前源码树，使用**同一份隔离数据副本**（`/tmp/homeos-perf/env/ab`），交替 3 轮；每端点 20 次预热 + 100 次串行 + 200 次并发（32 workers），keep-alive；取 3 轮中位数。
- 前端：`abf-old` = HEAD 源码 + 不可变旧 dist（`/tmp/homeos-perf/before-dist`）；`abf-new` = 当前源码 + 当前 dist；交替 3 轮；Edge 1440×900、DPR=1、`reducedMotion=reduce`；取中位数。
- 3D：同一对 dist，交替 3 轮；打开 `/display/<projectId>?performance-diagnostics=1`，等宿主 `.hb-interaction3d-runtime.is-ready`，读 iframe 内 `documentElement.dataset.performanceDiagnostics`；在真正的 WebGL canvas 上拖拽后采样。
- 启动：同一 env/ab，HEAD 与 CURRENT 交替 4 轮；记录 spawn→`/health/ready` 的 wall 与 `homeos_startup_duration_ms`。

> 为什么不直接用 baseline 报告的绝对值：2026-10-20 20:36 的全套 after 测量遇到系统 load average 8.72，所有端点（包括未改动的 healthz）一致变慢 26%~89%，前端 LCP 也整体上升；该批数据已判定为环境噪声并废弃。配对 A/B 的“同轮次对照”才是本报告的有效证据。

### 2.2 统计口径
- 延迟：p50/p95/p99；并发为 32 workers × 200 请求。
- DB/req：请求前后 scrape `homeos_db_queries_total` 差值 ÷ 请求数（store 无此指标，商品接口按代码路径标注）。
- 前端：LCP/CLS/longtask/Event Timing 来自 PerformanceObserver；encoded bytes 来自 CDP `Network.responseReceived`；请求数来自 CDP。
- 3D：稳态帧采样 3 次（每次间隔 500 ms），取中位数；draw calls/triangles/geometries/textures/programs 来自 `renderer.info`。
- 构建：`bun run check:bundle-budget` 对 `dist` 统计；逻辑字节用文件 size 求和，避免 APFS 块分配/克隆造成 `du` 假差异。

## 3. 代码变更、影响范围与回滚

| ID | 变更 | 影响范围 | 回滚 |

为什么 LCP 不能算改善：

前端结论：**确定性收益是少 8 个请求、少 44.5 KB stylesheet**；LCP/长任务没有可验证改善，报告不宣称。

## 7. 风险、限制与未达成项

1. **启动 −30% 未达成**：应用内 −3.1%、wall −6.4%。boot import 497 ms 是最大块；下一步必须做 import 拆分/延迟加载（例如把 agent/weather/license 的 import 移到首次使用时），而不是继续 gather。license 并发实验已证明重叠无收益并回退。
2. **条件请求的浏览器自动复用未验证**：手工 `curl` 304 与契约全过；但 Edge 155 在本机（headless/headed/CDP/persistent、最小复现服务器）始终不发 `If-None-Match`，只能证明缓存条目存在。真实浏览器/真机的二次加载收益待确认，报告不把它计入收益。
3. **store 缓存可见性**：TTL 5 s；6 个写入口已接失效钩子；若有脚本直接改 SQLite，最多 5 s 旧数据。`STORE_PRODUCTS_CACHE_TTL_SECONDS=0` 可立即关闭。
4. **3D 结构性开销未动**：每个 iframe 仍加载完整 SPA + 96 chunk；同屏多卡未测。详见 3D 专项报告。
5. **前端 LCP/长任务**：受系统负载与 3D 主导，本轮没有可验证改善；不宣称。
6. **healthz 轻微变慢**：新中间件 ~0.04 ms/请求，属可接受观测成本；若未来要极致，可改为采样或仅在特定路由启用。
7. **真机数据待补**：小米平板 8 的 LCP/TBT/INP、逐 iframe renderer.info、webglcontextlost 仍未采集；当前所有结论仅适用于本机 Edge。
